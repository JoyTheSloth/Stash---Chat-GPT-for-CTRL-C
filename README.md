## 📖 Overview

**Stash** is a local-first memory engine designed for developers who live in their terminal, browser, and IDE. Instead of losing vital code snippets, API keys, credentials, or commands to the void of traditional clipboard managers, Stash automatically captures, categorizes, and indexes your clipboard feed locally.

With **Ask Stash**, query your clipboard history in natural language — completely offline with zero telemetry and zero cloud sync.

---

## ✨ Key Features

- 🧠 **Ask Stash (Offline AI Search)**: Search & query your entire clipboard memory locally using natural language.
- 📐 **5 High-Density View Modes**:
  - **Detailed List Mode**: Comprehensive view with metadata & clip preview.
  - **Compact List Mode**: Ultra-dense list for rapid scanning.
  - **Detailed Grid Mode**: 2-column visual cards with category tags.
  - **3x3 Grid Mode**: High-density 9-item dashboard layout.
  - **4x4 Grid Mode**: Maximalist grid view.
- 📝 **Stash Pad (Auto-Categorizing Scratchpad)**: Temporary scratchpad that auto-sorts your quick notes, code snippets, and commands into categories.
- 📦 **Stash It (Multi-Clip Batching)**: Select and merge multiple clipboard items into a single, unified text block for batch pasting.
- ⚙️ **Retention & Instant Purge**: Set automatic auto-purge intervals (3 Days, 7 Days, or Forever) or clear your vault in 1 click.
- 🔒 **A Vault, Not Surveillance**: 100% local SQLite database with AES-256 local encryption. Zero outbound network calls.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0 or higher)
- `npm` or `yarn`

### Installation & Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/JoyTheSloth/Stash---Chat-GPT-for-CTRL-C.git
   cd Stash---Chat-GPT-for-CTRL-C
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local dev server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

---

## 🌐 Deploying on Vercel

1. Push your repository to GitHub.
2. Import the repository into [Vercel](https://vercel.com).
3. Set Framework Preset to **Vite**.
4. Click **Deploy**.

OpenGraph social preview metadata and custom favicon are pre-configured in `index.html` for rich link previews when sharing across WhatsApp, LinkedIn, Discord, and X (Twitter).
